# Plan - Two Shapes

## Goal

Ship a free offline pair of huge shapes a child and a grandparent can call same or different. The phone keeps the place in the six pairs.

## Approach

1. App Store Connect has no rejected version waiting.
2. Build Two Shapes in Expo: six pairs, Same, Different, and a saved place.
3. Run the full simulator regression on the Release binary for build 1.
4. Take three native screenshots, then upload that binary and submit it.
